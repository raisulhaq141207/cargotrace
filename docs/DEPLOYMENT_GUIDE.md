# CargoTrace: Deployment Guide

This guide details step-by-step instructions for deploying CargoTrace to cloud hosting environments (Render, Railway, or VPS) as specified in **Web Programming 2 — UAS Final Project (Slide 14 & 18)**.

---

## Option 1: Deploy to Render (Free Cloud PaaS)

[Render.com](https://render.com) offers free web service hosting for PHP/Docker applications.

### Steps:
1. **Push your repository to GitHub**.
2. Log in to [Render Dashboard](https://dashboard.render.com) and click **New + &rarr; Web Service**.
3. Connect your GitHub repository `cargotrace`.
4. Configure the Web Service:
   - **Environment**: `PHP` (or `Docker` using the included `Dockerfile`)
   - **Build Command**:
     ```bash
     composer install --no-dev --optimize-autoloader
     php artisan key:generate --force
     php artisan migrate --force --seed
     ```
   - **Start Command**:
     ```bash
     php artisan serve --host 0.0.0.0 --port $PORT
     ```
5. Add Environment Variables in the Render dashboard:
   - `APP_ENV`: `production`
   - `APP_DEBUG`: `false`
   - `APP_KEY`: *(Auto-generated by build command or copy from local `.env`)*
   - `DB_CONNECTION`: `sqlite` (or connect a free Render PostgreSQL/MySQL database)
   - `CARGOTRACE_DELAY_THRESHOLD_HOURS`: `12`
6. Click **Deploy**. Render will provide a public live URL (e.g. `https://cargotrace-xxxx.onrender.com`).

## Option 2: Deploy to Railway

[Railway.app](https://railway.app) automatically detects Laravel projects and Dockerfiles.

### Steps:
1. Log in to [Railway.app](https://railway.app).
2. Click **New Project &rarr; Deploy from GitHub repo**.
3. Select your `cargotrace` repository.
4. Add the following Railway Environment Variables:
   - `APP_KEY`: Base64 key generated by `php artisan key:generate --show`
   - `APP_ENV`: `production`
   - `APP_DEBUG`: `false`
   - `DB_CONNECTION`: `sqlite`
5. Railway will automatically build and assign a public domain with SSL.

## Option 3: Local Production Deployment (Apache / XAMPP VirtualHost)

If demonstrating locally on an Apache server:
1. Open `C:\xampp\apache\conf\extra\httpd-vhosts.conf` and append:
   ```apache
   <VirtualHost *:80>
       ServerName cargotrace.test
       DocumentRoot "C:/xampp/htdocs/Project UAS/public"
       <Directory "C:/xampp/htdocs/Project UAS/public">
           Options Indexes FollowSymLinks
           AllowOverride All
           Require all granted
       </Directory>
   </VirtualHost>
   ```
2. Open `C:\Windows\System32\drivers\etc\hosts` (as Administrator) and add:
   ```text
   127.0.0.1 cargotrace.test
   ```
3. Restart Apache in XAMPP Control Panel.
4. Access the application in browser at **`http://cargotrace.test`**.
